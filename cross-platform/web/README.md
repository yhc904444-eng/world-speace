# world speace 网页离线版 v1.5.1

把完整目录部署到静态 HTTPS 服务器即可使用。首次打开后，等待浏览器缓存词库完成，再使用浏览器“安装应用”或 Safari“添加到主屏幕”。之后可离线打开。浏览器需支持 ES 模块、dialog、Service Worker 和 CSS color-mix（例如当前 Chrome/Edge/Safari）。

本机预览：安装 Node.js 24，进入本目录执行 `node serve.mjs`，打开输出的本机地址。不要直接双击 HTML 文件。安装后的应用保留启动所用的来源地址；使用本机预览地址的安装需要保留同一地址和端口。

学习进度保存在这个浏览器、这个网站来源的本机存储。清理网站数据、隐私模式结束或浏览器回收存储可能删除进度；请定期在“我的 → 设置与备份”导出完整 JSON。不会自动同步其他设备或其他版本，迁移需手动导入备份。离线语音依赖浏览器提供的本机英语声音。

包内含完整词库、第三方 MIT 许可和 Noto Sans SC 中文字体（SIL OFL 1.1），无账号、后端、分析统计或在线词库。离线缓存更新不清除学习进度。Windows v1.5.0 与各平台 v1.5.1 的完整 JSON 备份相互兼容。
