# Android v1.5.1 启动修复验证

2026-10-21。Windows 版继续为 v1.5.0。

## 故障与修复

用户报告“离线词库未能加载。”，启动进入原始进度导出页。v1.5.0 APK 中存在 `assets/data\words.tsv`，缺少 `assets/data/words.tsv`。Android Activity 调用 `getAssets().open("data/words.tsv")`，因此返回资源 404；学习记录本身没有损坏的证据。

在无签名 APK 中把 ZIP 条目里的反斜杠转换为正斜杠，之后执行 zipalign 和原签名签署。转换前检查重名冲突，防止覆盖资源；最终签名 APK 必须通过精确条目名和全部资源 SHA256 校验。也以同样规则处理源码 ZIP。

使用 `Object.prototype.hasOwnProperty.call` 替代 `Object.hasOwn`，兼容缺少后者的 WebView。保持数据 Version 1、进度文件名和复习算法不变。

## 验证边界

没有连接的 Android 真机或已配置的模拟器。页面和桥接检查在浏览器中进行，APK 资源由本机工具按原始 ZIP 条目名读取；桥接使用模拟实现，测试数据均为合成记录。尚未验证 Android 安装器、具体机型的 WebView、系统文件选择器及离线语音。

Python 在 Windows 上读取 ZIP 时也会转换 `ZipInfo.filename` 中的反斜杠，因此 APK 预览使用 `ZipInfo.orig_filename` 做精确查找。仅通过解压后的文件或规范化后的文件名验证，会漏掉本次问题。

Android 的精确 ZIP 条目查找可参见 [AOSP AssetManager](https://android.googlesource.com/platform/frameworks/base/+/android14-qpr2-release/libs/androidfw/AssetManager.cpp)。
